## 🚀 Featured Projects

### 1 — GapGlint · *Evidence Intelligence Platform*

> *See the Gaps. Trace the Claims. Decide with Evidence.*

Most people making high-stakes decisions—scholarships, visas, grants—piece together information from 5–10 sources without knowing what conflicts, what's outdated, and critically, **what's missing**. GapGlint fixes exactly that.

| Feature | Description |
|---|---|
| 🔍 Multi-source ingestion | Web URLs + multi-page PDFs + manual notes |
| ⚛️ Atomic claim extraction | Sentence-level citations to original source |
| ⚡ Contradiction detection | Cross-source conflict identification |
| 🕳️ Negative space analysis | Identifies what all sources fail to mention |
| 📊 Decision Readiness Score | 0–100 confidence metric |
| ✅ Verification checklist | Prioritised action items for primary authorities |

**Stack:** `React 18` `TypeScript` `Vite` `Tailwind CSS` `FastAPI` `Python` `Google Gemini API` `PyMuPDF` `BeautifulSoup4` `httpx` `Vercel`

### 2 — EcoSort AI · *E-Waste Intelligence Assistant*

AI-powered identification and safety triage for electronic waste. Users upload or describe an item; the system classifies it, assesses hazardous component risk, and generates a step-by-step responsible disposal plan — bridging the gap between intent and action for sustainable e-waste management.

**Stack:** `Python` `FastAPI` `Google Gemini API` `React` `TypeScript`

### 3 — Recruit AI · *Enterprise Resume Intelligence System*

An AI-powered Resume × Job-Description matching engine with contradiction detection. Goes beyond keyword matching — it identifies discrepancies between claimed skills and demonstrated evidence, generates structured candidate profiles, and ranks candidates using verifiable reasoning chains.

**Stack:** `Python` `FastAPI` `Google Gemini API` `React` `TypeScript` `Tailwind CSS`

### 4 — Fair Student Support System · *Bias-Audited ML for Academic Intervention*
